## 정렬 알고리즘 정리 - 선택 정렬, 삽입 정렬

### 버블 정렬 (수업 내용 복습)
- 인접한 두 요소를 비교해 위치를 바꾸는 작업을 반복하여, 한 바퀴마다 최댓값이 맨 뒤로 이동

### 선택 정렬 (Selection Sort)
- 아이디어: 정렬되지 않은 구간에서 **최솟값을 찾아** 맨 앞 위치와 교환하는 과정을 반복
- 동작 과정 (`7 4 5 1 3`)
  1. 전체에서 최솟값 1 → 0번 위치와 교환: `1 4 5 7 3`
  2. 나머지에서 최솟값 3 → 1번 위치와 교환: `1 3 5 7 4`
  3. 나머지에서 최솟값 4 → 2번 위치와 교환: `1 3 4 7 5`
  4. 나머지에서 최솟값 5 → 3번 위치와 교환: `1 3 4 5 7`
- 특징
  - 시간 복잡도: 항상 O(n²) (이미 정렬되어 있어도 비교 횟수 동일)
  - 교환 횟수가 최대 n-1번으로 적음
  - 같은 값의 순서가 바뀔 수 있음 (불안정 정렬)
- 코드: `selection_sort.c`

### 삽입 정렬 (Insertion Sort)
- 아이디어: 정렬된 구간을 앞쪽에 두고, 다음 요소를 **알맞은 위치에 끼워 넣는** 과정을 반복
- 동작 과정 (`7 4 5 1 3`)
  1. 4를 삽입: `4 7 5 1 3`
  2. 5를 삽입: `4 5 7 1 3`
  3. 1을 삽입: `1 4 5 7 3`
  4. 3을 삽입: `1 3 4 5 7`
- 특징
  - 시간 복잡도: 최악 O(n²), 이미 정렬된 경우 O(n)
  - 거의 정렬된 데이터에서 빠름
  - 같은 값의 순서가 유지됨 (안정 정렬)
- 코드: `insertion_sort.c`

### 세 정렬 비교
| 구분 | 버블 | 선택 | 삽입 |
|------|------|------|------|
| 핵심 동작 | 인접 요소 교환 | 최솟값 선택 후 교환 | 알맞은 위치에 삽입 |
| 최악 시간 복잡도 | O(n²) | O(n²) | O(n²) |
| 이미 정렬된 경우 | O(n²) (기본 형태) | O(n²) | O(n) |
| 안정성 | 안정 | 불안정 | 안정 |
