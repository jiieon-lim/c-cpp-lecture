## 3주차 - 제어문과 함수

### 제어문
- if문: 조건이 참일 때만 코드 실행
- if~else문: 조건에 따라 둘 중 하나 실행
- 다중 if~else: 여러 조건을 순서대로 검사
- 중첩 if: if 안에 if를 넣어 세밀하게 조건 분기
- switch case: 하나의 값에 따라 여러 case 중 하나 실행 (break로 종료)

### 반복문
- while: 조건이 참인 동안 반복 (조건을 먼저 검사)
- do~while: 일단 한 번 실행 후 조건 검사
- for: 초기화·조건·증감식을 한 줄에 작성하는 반복문
- 다중 for: for문 안에 for문을 중첩 (표, 패턴 출력 등에 사용)
- break: 반복문/switch를 즉시 종료
- continue: 현재 반복만 건너뛰고 다음 반복으로 이동
- goto: 지정한 위치로 실행 흐름을 강제 이동 (거의 사용 안 함)
